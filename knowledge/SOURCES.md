# Evidence register — Knowledge Baseline v0.1

Scope: the seven pinned repository snapshots in [REPOSITORIES.md](REPOSITORIES.md). Audit: 26 October 2026; consolidation: 27 October 2026. [STATUS.md](STATUS.md) summarizes the operational boundary.

## Classification and authority

- **VERIFIED:** the stated object was inspected, such as committed code, a schema, a published document or a recorded historical result. Each entry limits what this verifies. Inspecting a report does not rerun its experiment.
- **DOCUMENTED DESIGN:** an existing source specifies an intended model or convention; implementation and interoperability are not thereby established.
- **PROPOSAL:** a possible future action or mechanism, requiring a separate decision.
- **UNKNOWN:** evidence is absent, incomplete, stale for the requested claim, or not independently checked.

Original repository sources own their specifications. This register indexes them; it does not replace protocol definitions. Static sources never prove current Bitcoin ownership, current relay retention or current deployment state. No new live authorization or economic test was run for this consolidation.

## Artifact integrity and historical verification boundary

For BM-07, the raw public JSON is 2,131 bytes with SHA-256:

`7be8b35184a6ee4381448fd4e67bf586b57b628302c7d2db26fd2699332b2efb`

Its signed message is 1,092 UTF-8 bytes with SHA-256:

`bfa6b84854419d3629373ecf66cf6869766c7c606dd279f991941d027e42f833`

These are distinct hashes. The message's authority snapshot (972169) is not the later live-check tip.

BM-09 records the 25 October 2026 Nostr test using kind 1, relay `wss://relay.damus.io`, and a Name-derived `d` tag. It separates relay acceptance from independent discovery and Bitcoin authorization. Its original execution report was partially truncated, and the closure did not independently recover a complete raw historical relay/Bitcoin evidence bundle. Tip 973074 and the execution outcome are preserved as recorded historical evidence, not presented as a new replay performed by this hub.

Nostr delivers a reference; the existing Bitcoin/BIP-322 rules verify the binding. Publisher identity is not delegated Bitcoin authority. A completed subscription does not prove complete historical discovery, retention, supersession or revocation. Authorization must still satisfy both current holders and confirmed, unspent outputs when checked. No signatures or private keys are copied into this register.

## How to extend this register

Add only a traceable claim with an explicit verification boundary, owning repository, exact path and immutable commit where available. Mark unresolved provenance UNKNOWN. Cite human decisions as decisions; do not manufacture Git evidence for them. Changing a source's normative rules requires a separate authorization outside this documentation baseline.
